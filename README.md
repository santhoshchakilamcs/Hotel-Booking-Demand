# Hotel-Booking-Demand

This file contains the basic EDA and f1_scores of different models that has perfomed on this dataset.

The Ramdom Forest Classifier and the XGBoost Classifier has the highest f1-score(0.88).

## Note on the figure above

The 0.88 F1 figure is stated in the original README above. It was not re-run or newly verified as part of this README-only update, so it is kept here attributed to the original README, not presented as a newly verified result.

## The two notebooks

This repo contains two hotel booking demand notebooks, covering a resort hotel and a city hotel. One notebook focuses on exploratory data analysis and model comparison, and the other extends that work. Readers should open the notebooks to see which models, features, and outputs each one contains, as the notebooks themselves are the source of record for the analysis.

## Data source

The dataset covers hotel booking demand for a resort hotel and a city hotel, as described in the original README. Booking patterns, cancellation behaviour, and demand conditions change over time, so results from this historical dataset should not be treated as a forecast for current hotel demand.
